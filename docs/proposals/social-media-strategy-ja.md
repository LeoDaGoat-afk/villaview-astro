## エグゼクティブサマリー

貴ホテル様には現在、弊社プラットフォーム上に**公式サイト**と**直予約システム**が整備されており、技術基盤は完成しております。次の成長ステップとして、**ソーシャルメディアによる集客チャネル構築**をご提案いたします。

本提案では、以下の 3 つの価値をお届けします：

1. **OTA（Booking.com / Expedia 等）への手数料流出を年間数百万円規模で削減**
2. **訪日インバウンド客の直予約比率を 6 ヶ月で 30% → 50% へ引き上げ**
3. **トライアル期間中、弊社が運用代行いたします**（実績ベースで継続判断）

## 2. なぜソーシャルメディアが必要か

### 2.1 旅行者の意思決定プロセスの変化

**従来（〜2015 年頃）**：
```
旅行先決定 → 検索 → 比較 → 予約
```

**現在**：
```
SNS（Instagram / 小紅書 / TikTok）で見て憧れる
  ↓
「行きたい！」という感情が先行
  ↓
ブランド名で検索 → 公式サイトで予約
```

つまり、**ソーシャルメディアに存在しない＝そもそも旅行先候補に入らない**時代です。

### 2.2 訪日インバウンドへの影響

JNTO（日本政府観光局）の調査では、**訪日外国人旅行者の 96.3% が出発前にインターネット情報を参照**し、その多くがソーシャルメディアです。

特に**中国人旅行者の小紅書（RED）依存度は極めて高く**、富士山周辺のホテル選びでは小紅書の投稿数が予約数に直結します。

### 2.3 自社メディアという「資産」

広告は支払いを止めると効果も止まりますが、ソーシャルメディアの投稿は**永続的な資産**です。3 年前の良質な投稿が今でも検索流入を生み出します。

## 3. 推奨プラットフォーム（優先度順）

### 🔥 Tier 1：必須（初月内開設）

#### A. Google ビジネスプロフィール
- **費用**：完全無料
- **役割**：「山中湖 ホテル」検索時に右側に表示されるホテル情報カード
- **効果**：開設だけで月間検索流入 +30%、口コミ評価が SEO スコアに直結

#### B. Instagram
- **費用**：無料（有料広告は任意）
- **役割**：欧米・港台・国内若年層への入口
- **効果**：富士山・山中湖は世界的な人気ハッシュタグ。質の高い投稿は半年で 1,000–5,000 フォロワー、月間リーチ 5–20 万到達可能

#### C. TripAdvisor
- **費用**：無料
- **役割**：訪日外国人の意思決定で 70% 以上が参照
- **効果**：オーナー登録で口コミ返信権限を取得、評価管理が可能。未登録の場合、ネガティブな投稿が一方的に表示されるリスク

### 🟡 Tier 2：日本国内特化（1–2 ヶ月以内）

#### D. LINE 公式アカウント
- **費用**：月 ¥0–¥5,000（送信通数による）
- **役割**：日本人リピーター獲得の最強ツール
- **効果**：滞在中に友だち追加 → ゴールデンウィーク・紅葉・年末等のキャンペーンを直接配信、リピート率 +30% 期待

#### E. X（Twitter）
- **費用**：無料
- **役割**：富士山初冠雪・桜開花・紅葉等、季節イベントの即時発信
- **効果**：1 投稿が数千〜数万拡散することも

### 🟢 Tier 3：訪日インバウンド特化（2–3 ヶ月以内）

#### F. 小紅書（RED）
- **費用**：無料
- **役割**：中国本土からの訪日客への最重要接点
- **効果**：1 つのバイラル投稿で 1–2 ヶ月の安定予約をもたらすことも

#### G. TikTok / 抖音 / YouTube ショート
- **費用**：無料
- **役割**：30 秒動画で「露天風呂 + 富士山 + 和食」の世界観訴求
- **効果**：アルゴリズム的に新規アカウントでも数万再生が可能

## 6. 弊社による運用代行プラン（トライアル期間）

### 6.1 トライアル期間：3 ヶ月

ソーシャルメディアの効果は短期では実感しにくいため、**3 ヶ月のトライアル期間**を設定し、明確な KPI で成果検証いたします。

### 6.2 含まれるサービス

| 項目 | 内容 |
|---|---|
| **アカウント設定** | 6 プラットフォームの新規開設・プロフィール最適化・ロゴ／カバー画像設置・公式 Web リンク統合 |
| **コンテンツ制作** | 月間 20 投稿（プラットフォーム横断）。クライアント側からのお写真ご提供＋弊社編集 or 月 1 回の撮影日同行 |
| **配信管理** | 全プラットフォームへの配信スケジュール作成・実施 |
| **コミュニティ管理** | DM 返信・コメント返信・口コミ対応（多言語：JP / EN / ZH） |
| **月次レポート** | KPI 達成状況・改善提案・競合分析 |
| **緊急対応** | ネガティブ口コミ・誤情報拡散時の対応 |

### 6.3 トライアル料金

**月額 ¥150,000（税別）× 3 ヶ月**

※ 撮影費・広告出稿費は別途実費精算
※ 4 ヶ月目以降は実績に応じて継続／内製化／プラン変更を選択可能

### 6.4 トライアル成果の判定基準

3 ヶ月後、以下のいずれかが達成されていれば「成功」と判定：

- ✅ Instagram フォロワー数：500 人以上
- ✅ Google ビジネスプロフィール検索表示数：月 +50% 以上
- ✅ 公式サイト経由の予約数：月 +20% 以上
- ✅ 訪日外国人客比率：+5pt 以上

→ 達成時、月額継続契約へ移行を推奨。
→ 未達成時、原因分析レポートを納品し、戦略再設計または契約終了を選択可能（違約金なし）。
