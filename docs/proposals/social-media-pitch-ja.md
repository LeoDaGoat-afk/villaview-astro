# 富士山ガーデンホテル本館 様
## ソーシャルメディア戦略 ご提案書
### 〜 公式サイトの集客力を最大化する技術と運用 〜

---

## はじめに

貴ホテル様には既に、弊社プラットフォーム上に**多言語対応公式サイト（日本語・英語・中国語）**と**直予約システム**が整備されております。

本提案では、この強固な技術基盤を活かし、**ソーシャルメディアによる新たな集客チャネルの構築**をご提案いたします。OTA（外部予約サイト）に依存しない、**公式サイト主導の集客モデル**へとシフトしてまいります。

---

## 1. 現状の機会損失

貴ホテル様の現在の集客は、ブランド名検索と OTA 経由が中心となっております。一方、潜在的なお客様の多くは**ソーシャルメディアで宿泊先を発見・検討**しています。

### 1.1 現代の旅行者の意思決定プロセス

```
〔従来〕
   旅行先決定 → 検索 → 比較 → 予約

〔現在〕
   Instagram / 小紅書 / TikTok で発見・憧れ
        ↓
   「行ってみたい」という感情
        ↓
   ホテル名で検索 → 公式サイトで予約
```

つまり、**ソーシャルメディアに存在しないことは、検討候補にすら入らない**ことを意味します。

### 1.2 訪日インバウンド客の情報源

JNTO（日本政府観光局）調査によれば、**訪日外国人旅行者の 96% 以上が出発前にインターネット情報を参照**し、その中心がソーシャルメディアです。

特に：
- **欧米・港台のお客様** → Instagram / TripAdvisor / Google 検索
- **中国本土のお客様** → 小紅書（RED）
- **国内リピーター** → LINE / X（Twitter）

### 1.3 富士山・山中湖というブランド資産の活用

「富士山」「山中湖」は世界的に強力な検索キーワード／ハッシュタグです。

- Instagram「#mtfuji」投稿：**約 350 万件**
- Instagram「#山中湖」投稿：**約 12 万件**
- 小紅書「富士山」検索：**月間約 50 万閲覧**

→ この巨大な検索流量に対し、**現状では貴ホテル様が露出する場が存在しない状態**です。

## 2. 弊社が提供する技術

### 2.1 AI 駆動型コンテンツ生成エンジン

弊社プラットフォームには、ホテル業界に特化した AI コンテンツエンジンを内蔵しております。

**主な機能**：

| 機能 | 内容 |
|---|---|
| **自動文案生成** | 1 つの主題（例：「初冠雪の富士山」）から、各プラットフォーム最適化された文案を自動作成 |
| **多言語対応** | 日本語・英語・簡体字中国語を同時生成（自然な現地表現） |
| **プラットフォーム最適化** | Instagram は感情的に、X は簡潔に、LINE は親密に、と各 SNS の文化に合わせて自動調整 |
| **ハッシュタグ提案** | 季節・地域・トレンドに基づく最適ハッシュタグを自動生成 |
| **画像最適化** | 1 枚の写真から各プラットフォームの推奨サイズ（1:1 / 9:16 / 16:9）を自動生成 |

### 2.2 マルチプラットフォーム自動配信

複数のプラットフォームへの投稿スケジュールを **1 つのダッシュボードから一元管理**できます。

**対応プラットフォーム**：

| プラットフォーム | 主な対象客層 |
|---|---|
| **Instagram** | 欧米・港台・国内若年層 |
| **Facebook** | 欧米中年家庭客 |
| **X（Twitter）** | 国内 + 欧米のリアルタイム情報共有 |
| **LINE 公式アカウント** | 国内リピーター |
| **TikTok** | グローバル 18–30 歳 |
| **YouTube Shorts** | 長期的な検索流入 |
| **Google ビジネスプロフィール** | Google マップ・ホテル検索結果 |
| **TripAdvisor** | 訪日外国人 |

### 2.3 公式サイトとの自動連携

弊社プラットフォームの強みは、ソーシャルメディアと公式サイト・予約システムが**シームレスに連携**することです。

- 各投稿に**自動でトラッキングリンク**が付与され、どの投稿から予約に至ったかを計測
- 季節限定プラン公開時、**自動で全 SNS にプロモーション投稿を配信**
- 客室の空室状況に連動し、**繁忙期前には早期予約促進、閑散期には特価プロモーション**を自動切り替え

### 2.4 顧客対応の自動化

- **DM・コメントへの自動返信**（多言語対応、AI が文脈を理解して回答）
- **TripAdvisor・Google レビューへの返信案を AI が下書き**（管理者の承認のみ）
- **ネガティブな投稿の早期検知**とアラート

### 2.5 データ分析ダッシュボード

毎月自動で以下のレポートを生成いたします：

- 投稿パフォーマンス（リーチ・エンゲージメント・クリック数）
- フォロワー増減推移
- 競合ホテルとの比較
- 投稿時間・テーマの最適化提案
- 公式サイトへの流入経路分析

## 3. 期待される効果

### 3.1 公式サイト訪問数の増加

ソーシャルメディアの各投稿が公式サイトへの流入口となります。

**6 ヶ月後**（業界ベンチマーク基準）：
- Instagram 経由の月間サイト訪問：**500–1,500 件**
- Google ビジネスプロフィール経由：**月間 +30% 以上**
- LINE 公式アカウント友だち：**500–1,500 名**
- TripAdvisor 露出向上による海外検索流入

### 3.2 ブランド認知度の向上

- 富士山・山中湖関連検索における露出機会の確立
- 訪日インバウンド客にとっての**第一想起ホテル**へのポジショニング
- 季節イベント（紅葉・雪化粧・桜）における**話題性の獲得**

### 3.3 リピーター育成

LINE 公式アカウントを通じた**継続的な顧客接点**を構築：
- ご宿泊後のお礼メッセージ
- 季節ごとのキャンペーン案内
- 限定プランの先行案内

### 3.4 訪日外国人客の比率向上

多言語ソーシャルメディア運用により、**非日本語圏のお客様の獲得チャネル**を確立：
- 英語圏：Instagram + TripAdvisor
- 中華圏：Instagram（繁体）+ Facebook + 港台向け
- 韓国圏：Instagram + Naver

### 3.5 公式サイト直予約比率の向上

外部予約サイト（OTA）への依存度を下げ、**公式サイトでの直接予約**へとお客様を誘導いたします。

これにより：
- お客様の情報を直接保有（リピート促進が可能に）
- 予約条件の柔軟な対応
- ブランド体験の一貫性

## 4. 貴ホテル様にお願いしたい事項

弊社が技術と運用を担当いたしますが、ホテル様のご協力なくして高品質なコンテンツは生み出せません。以下のご協力をお願いいたします。

### 4.1 必須事項

#### A. 各プラットフォームのアカウント開設・権限委譲
弊社が代行して開設・運用するため、以下の登録・認証手続きにご協力ください：

- **Google ビジネスプロフィール**：オーナー認証（郵便はがき受領、約 2 週間）
- **Instagram / Facebook**：Meta Business アカウントの開設、ホテル名義での認証（約 1–2 週間）
- **LINE 公式アカウント**：LINE Business ID 取得、ホテル名義での認証（約 1 週間）
- **X（Twitter）**：認証マーク申請（任意、ブランド保護に有効）
- **TripAdvisor**：オーナー登録（即時）

→ いずれもホテル様名義で取得し、運用権限のみ弊社が代理で行使する形式となります。**所有権は常にホテル様にあります**。

#### B. 写真素材のご提供
品質の高いコンテンツには、現地でしか撮影できない素材が不可欠です。

**月間で必要な素材**（目安）：

| 種別 | 枚数／月 | 撮影者 |
|---|---|---|
| 客室・館内（朝の自然光が美しい時間帯）| 8–12 枚 | フロント・客室スタッフ |
| 朝食・夕食（盛り付け直後）| 4–6 枚 | レストランスタッフ |
| 露天風呂・大浴場（営業時間外）| 2–4 枚 | 清掃時間に施設担当者 |
| 季節の風景（富士山・山中湖）| 3–5 枚 | お時間のあるスタッフ |
| イベント・お客様の様子（同意のあるもののみ）| 任意 | 当日担当者 |

→ **スマートフォンでの撮影で十分**です。弊社の AI が自動で色補正・トリミング・ロゴ入れを行います。

→ 季節の特別なタイミング（初冠雪・桜満開・紅葉ピーク）には、**現地撮影日**を別途設定することも可能です。

#### C. 文章素材のご提供（最初の 1 ヶ月のみ集中的に）

ホテル独自の世界観を AI に学習させるため、以下を初期にご提供いただきます：

- ホテルのこだわり・コンセプト（300–500 字）
- 客室の特徴・推しポイント（各客室タイプごと）
- お料理・温泉のこだわり
- 過去のお客様からのお褒めの言葉（あれば）

→ 1 度ご提供いただければ、以降は AI が「ホテルの声」として自動再現いたします。

#### D. ブランドガイドラインのご共有

- ロゴデータ（PNG / SVG）
- ブランドカラー（公式サイトと統一済み：#2F555A / #E8633A）
- フォント（Hiragino / Yu Gothic 系）
- NG 表現（避けたい言葉・トーン）

### 4.2 推奨事項

#### E. 月次フィードバックミーティング（30 分）
毎月末、レポートをご覧いただき、以下を 30 分で共有：
- 反響の大きかった投稿
- 翌月のプロモーション計画
- 季節イベント・特別企画のご相談

#### F. お客様の声の共有
- ご宿泊いただいたお客様の素敵なエピソード
- 公開可能な口コミ・お礼の手紙
- 印象的な質問・問い合わせ内容

→ これらが**最も強力なコンテンツ素材**となります。

### 4.3 任意事項

#### G. インフルエンサー招待への参加
弊社が選定したインフルエンサーをご招待する際、**1 泊のご招待**をご検討いただけますと、自然な紹介投稿が拡散効果を生みます。

#### H. 季節イベントの企画協力
桜・紅葉・初冠雪などのタイミングで、**SNS 限定の特別プラン**を企画する際、ご相談・ご協力をお願いする場合があります。
