## 引言

贵酒店现已在我方平台上完成**多语言官方网站（日文・英文・中文）**与**直接预约系统**的部署，技术基础牢固。

本次提案旨在依托这一坚实基础，构建**通过社交媒体的全新集客渠道**，实现从依赖 OTA（外部预约平台）向**官网主导集客模式**的转变。

---

## 1. 当前的机会损失

贵酒店目前的集客主要依赖品牌名搜索与 OTA 渠道。然而大量潜在客户实际上正通过**社交媒体发现并决策入住目的地**。

### 1.1 现代旅行者的决策路径变化

```
〔过去〕
   决定旅行目的地 → 搜索 → 比较 → 预订

〔现在〕
   在 Instagram / 小红书 / TikTok 上发现并被吸引
        ↓
   产生「想去」的情感
        ↓
   按酒店名搜索 → 在官网预订
```

也就是说，**不在社交媒体上存在 = 根本不会进入考虑名单**。

### 1.2 访日入境客的信息来源

根据 JNTO（日本国家旅游局）调查，**96% 以上的访日外国旅客会在出发前查询互联网信息**，而其中以社交媒体为主。

具体来看：
- **欧美・港台客** → Instagram / TripAdvisor / Google 搜索
- **中国大陆客** → 小红书（RED）
- **日本国内回头客** → LINE / X（Twitter）

### 1.3 「富士山」「山中湖」品牌资产的价值

「富士山」「山中湖」是世界级强力搜索关键词与话题标签：

- Instagram「#mtfuji」帖子：**约 350 万条**
- Instagram「#山中湖」帖子：**约 12 万条**
- 小红书「富士山」搜索：**月浏览约 50 万次**

→ 面对如此巨大的搜索流量，**贵酒店目前没有任何曝光场所**。

## 2. 我方提供的技术

### 2.1 AI 驱动的内容生成引擎

我方平台内置面向酒店行业的 AI 内容引擎。

**核心功能**：

| 功能 | 内容 |
|---|---|
| **自动文案生成** | 输入一个主题（例：「初冠雪的富士山」），自动为各平台生成最优化文案 |
| **多语言对应** | 同时生成日文・英文・简体中文（地道现地表达） |
| **平台个性化** | Instagram 偏感性・X 偏简洁・LINE 偏亲密，根据各 SNS 文化自动调整 |
| **话题标签推荐** | 基于季节・地区・趋势自动生成最优 hashtag |
| **图片优化** | 一张照片自动生成各平台推荐尺寸（1:1 / 9:16 / 16:9） |

### 2.2 多平台自动发布

将多个平台的发布计划**统一在一个仪表盘上集中管理**。

**支持平台**：

| 平台 | 主要客群 |
|---|---|
| **Instagram** | 欧美・港台・国内年轻客 |
| **Facebook** | 欧美中年家庭客 |
| **X（Twitter）** | 国内 + 欧美实时信息 |
| **LINE 公式账号** | 国内回头客 |
| **TikTok** | 全球 18–30 岁 |
| **YouTube Shorts** | 长期搜索流量 |
| **Google 商家资料** | Google 地图・酒店搜索结果 |
| **TripAdvisor** | 访日外国人 |

### 2.3 与官网的自动联动

我方平台的核心优势在于：社交媒体与官方网站・预约系统**无缝连接**。

- 各帖子**自动附带追踪链接**，可统计每篇贴文带来的预订数
- 发布季节限定方案时，**自动向所有 SNS 推送促销帖**
- 联动客房空房率，**旺季前推送早鸟促销，淡季推送特惠促销**，自动切换

### 2.4 客户对应自动化

- **DM・评论自动回复**（多语言对应，AI 理解上下文回答）
- **TripAdvisor・Google 评价的回复草稿由 AI 起草**（管理者审批后发布）
- **负面帖子早期检测**与告警

### 2.5 数据分析仪表盘

每月自动生成以下报告：

- 帖子表现（触达数・互动数・点击数）
- 粉丝增减趋势
- 与同业酒店的对标
- 发布时间与主题的优化建议
- 官网流量来源分析

## 3. 预期效果

### 3.1 官网访问量增加

每篇社交帖子都将成为通往官网的入口。

**6 个月后**（行业基准）：
- Instagram 引流月度官网访问：**500–1,500 次**
- Google 商家资料引流：**月度 +30% 以上**
- LINE 公式账号好友：**500–1,500 名**
- TripAdvisor 曝光提升带来的海外搜索流量

### 3.2 品牌认知度提升

- 在富士山・山中湖相关搜索中确立曝光机会
- 在访日入境客心智中占据**首选回想酒店**地位
- 季节事件（红叶・初雪・樱花）的**话题获取**

### 3.3 回头客培养

通过 LINE 公式账号建立**持续的客户接点**：
- 入住后致谢消息
- 季节性活动通知
- 限定方案优先告知

### 3.4 访日外国人客比率提升

通过多语言社交运营，建立**非日语圈客户的获取渠道**：
- 英语圈：Instagram + TripAdvisor
- 中华圈：Instagram（繁体）+ Facebook + 港台向
- 韩语圈：Instagram + Naver

### 3.5 官网直订比率提升

降低对外部 OTA 的依赖，**引导客人到官方网站直接预订**。

由此带来：
- 客户信息直接掌握（便于后续回头促进）
- 预约条件灵活对应
- 品牌体验一致性

## 4. 需要贵酒店配合的事项

我方负责技术与运营，但若无贵酒店配合，无法产出高质量内容。请配合以下事项。

### 4.1 必须事项

#### A. 各平台账号开通与权限委托
我方将代为开设运营，请配合以下注册・认证手续：

- **Google 商家资料**：业主认证（明信片接收，约 2 周）
- **Instagram / Facebook**：Meta Business 账号开设、酒店名义认证（约 1–2 周）
- **LINE 公式账号**：LINE Business ID 取得、酒店名义认证（约 1 周）
- **X（Twitter）**：认证标志申请（任意，对品牌保护有效）
- **TripAdvisor**：业主登记（即时）

→ 所有账号均以贵酒店名义注册，仅运营权限由我方代为行使。**所有权始终归贵酒店所有**。

#### B. 提供照片素材
高质量内容离不开现地拍摄的素材。

**月度需要素材**（参考）：

| 类别 | 张数／月 | 拍摄者 |
|---|---|---|
| 客房・馆内（晨光柔和时段）| 8–12 张 | 前台・客房员工 |
| 早餐・晚餐（出菜瞬间）| 4–6 张 | 餐厅员工 |
| 露天风吕・大浴场（营业时间外）| 2–4 张 | 清扫时段设施员工 |
| 季节景色（富士山・山中湖）| 3–5 张 | 闲暇员工 |
| 活动・客人（仅经同意）| 任意 | 当日负责人 |

→ **手机拍摄即可**。我方 AI 自动完成色彩调整・裁剪・logo 嵌入。

→ 季节特殊时刻（初冠雪・樱花满开・红叶高峰）可另行安排**现地摄影日**。

#### C. 提供文字素材（仅初月集中）

为让 AI 学习酒店独有世界观，需在初期提供：

- 酒店理念・特色（300–500 字）
- 各类客房特点・卖点
- 餐饮・温泉的讲究之处
- 过往客人褒奖之言（如有）

→ 仅需提供一次，之后 AI 即可自动再现「酒店之声」。

#### D. 共享品牌规范

- Logo 数据（PNG / SVG）
- 品牌色（与官网统一：#2F555A / #E8633A）
- 字体（Hiragino / Yu Gothic 系）
- NG 表达（应避免的词语・语气）

### 4.2 推荐事项

#### E. 月度反馈会议（30 分钟）
每月底审阅报告，30 分钟内分享：
- 反响显著的帖子
- 次月促销计划
- 季节活动・特别企画商讨

#### F. 客人故事分享
- 入住客人的精彩故事
- 可公开的好评・感谢信
- 印象深刻的提问・咨询内容

→ 这是**最强的内容素材**。

### 4.3 任意事项

#### G. 网红邀约配合
我方筛选网红邀约入住时，请考虑**赠送 1 晚**，自然种草帖能带来病毒传播效果。

#### H. 季节企画协助
樱花・红叶・初冠雪等时机，企画**SNS 限定特别方案**时，需要协商配合。
